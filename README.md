# Lab08_TO

El [Avance 5](AVANCE_5.md) incluye el código de Singleton y Observer aplicado
a SIDEA, sus diagramas y la justificación de cada patrón.

Para ejecutar la demostración de SIDEA desde esta carpeta:

```powershell
g++ -std=c++14 -Wall -Wextra -pedantic demo_sidea.cpp -o demo_sidea.exe
.\demo_sidea.exe
```

`demo_sidea.cpp` y `main.cpp` son programas separados; no se compilan juntos.
